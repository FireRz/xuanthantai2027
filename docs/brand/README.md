# Thư mục nhận diện & hình trang trí

## 1. Logo công ty

| File | Yêu cầu |
|------|---------|
| `logo.svg` (hoặc `logo.png`) | Bản màu, nền trong suốt; PNG ≥ 512px |
| `logo-white.svg` (hoặc `logo-white.png`) | Bản trắng, dùng trên nền đỏ |

## 2. Hình trang trí Tết cho banner (ADR-009 U17)

| File | Yêu cầu |
|------|---------|
| `tet-mai.png` | Cành mai vàng, **PNG nền trong suốt**, rộng ≥ 1600px |
| `tet-dong-xu.png` | Đồng xu / thỏi vàng Thần Tài, PNG nền trong suốt, ≥ 800px |
| `tet-banner.jpg` *(tùy chọn)* | Nếu có sẵn một ảnh banner Tết hoàn chỉnh, rộng ≥ 2400px |
| `LICENSE.txt` | Ghi **nguồn và giấy phép** của từng ảnh (VD: mua trên Shutterstock/Freepik Premium, đội thiết kế công ty tự làm…) |

Lưu ý: ảnh lấy từ Google Hình ảnh thường **có bản quyền**; chỉ dùng ảnh có giấy phép rõ ràng cho mục đích thương mại.
